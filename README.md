# Gboard 双拼提示

## 安装

从 [Releases](https://github.com/rikumi/gboard-shuangpin-hints/releases) 下载 APK，任选一种方式安装：

- **LSPosed**：安装模块 APK，在 LSPosed 中启用模块并勾选 Gboard，重启 Gboard。
- **LSPatch**：安装模块 APK，卸载原版 Gboard，再安装同一 Release 中的 Gboard 修补版。

在 Gboard 中选择双拼方案，然后打开模块设置。

## 功能

- 显示双拼提示
- 根据声母显示可用韵母
- 隐藏复声母
- 每字初始时只显示声母
- 根据声母显示单韵母
- 提示字号
- 隐藏 Gboard 数字提示
- 分词键改为行内大写
- 无刻模式
- 隐藏模块启动器图标
- 隐藏 Gboard 启动器图标
- 重启 Gboard
